Review filters

This opt-in filter includes namespace-only edits in moved files. It matches exact replacements supported by unambiguous namespace-declaration changes, not compiler equivalence. Review the detected mapping and dependency diagrams; runtime bindings may change. Identical warning pragmas are allowed only with exact full-source replacements. Changed pragmas, conditional directives, mixed edits, comments, literals and other unsupported syntax stay visible.

Designer and migration filters are on by default and independent of generated-code detection. They match filenames and Migrations directory segments case-insensitively. Renames into or out of these categories and file-mode changes stay visible.

Generated-code filtering is on by default. It recognizes .designer/.generated/.g/.g.i filenames, TemporaryGeneratedFile_ files and leading C#/VB auto-generated comments. Repository .editorconfig generated_code overrides are read from both Git snapshots. Mixed member-level attributes and generated/handwritten transitions stay visible. This does not require the language server.

Ignored files remain available and are not marked viewed. Class/type declarations stay visible when their references only repeat the detected rename. Detection is syntax-based, not semantic proof: mixed edits, strings, comments, ambiguous mappings and unsupported syntax stay visible. Formatting detection preserves token boundaries and literal contents. Using changes can affect name resolution.
